## 🎯 Objetivo del proyecto

El objetivo principal es afianzar conceptos clave de programación en JavaScript, entre ellos:

- Sintaxis básica y fundamentos  
- Condicionales, bucles y funciones  
- Manipulación del DOM  
- Manejo de eventos  
- Fetch API y Promesas  
- Asincronía moderna con ES6+  
- Trabajo estructurado con carpetas y módulos
